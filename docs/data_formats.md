# 数据格式

界面控件不读存档。调用方把下面的字典交给对应的 `apply_engine` 或 `configure`，再调用 `open()`。控件不决定玩法结算。

## 顶栏

入口是 `top_bar.apply_engine(data)`。按下按钮时顶栏发出 `action_pressed(id)`，不在顶栏里打开界面。

默认四个按钮：

| id | 文字 | 画廊里打开 |
| --- | --- | --- |
| `journal` | 手记 | 手记弹窗 |
| `evidence` | 证据 | 证据栏 |
| `status` | 状态 | 通知 |
| `settings` | 设置 | 原来的设置窗口 |

`stats` 仍是 `[{label, value}]`。`day`、`total`、`ap`、`ap_max` 交给天数角标。角标显示「第 N 天」和「当前/上限」，`total` 先留给引擎，角标上不写总天数。

## 手记弹窗

入口是 `journal_book.apply_engine(data)`，然后 `open()`。控件不读存档，也不写手记。按下关闭后发出 `closed`。

调用方按天组好再传入。控件不把散落的日志按天数合并，也不补上没传来的空日子。数组里的顺序就是翻页顺序。`apply_engine` 不接收页码。`open()` 停在最后一页，也就是数组里的最后一天。已经打开时再次 `apply_engine`，页码能留在范围内就留着，超出就夹到最后一页。`show_day(day)` 按 `day` 数字跳到对应页；没有这一天就不动。

### `days`

数组。不是数组就当成没有书页。一项不是对象就跳过。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `day` | 整数 | 这一页的天数，显示成 `Day N`。小于 1 的整页跳过。同一数字可以出现两次，控件不会合并 |
| `events` | 数组 | 这一天触发的事件。缺省当作空数组 |
| `actions` | 数组 | 这一天玩家做出的操作和结果。缺省当作空数组 |

一天可以只有事件，或只有操作。两边都空时，这一页仍保留，书页上写明当天没有事件、也没有操作。

### `events` 的一项

不是对象就跳过。`title` 和 `text` 都空，或都没传，这一项跳过。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | 字符串 | 同一次打开里唯一。控件只保存，不拿它查表 |
| `title` | 字符串 | 事件名，写在正文上面。空则不显示这一行 |
| `text` | 字符串 | 事件经过。空则不显示这一段。过长时在书页内部滚动，不另开一页 |

### `actions` 的一项

不是对象就跳过。`action` 和 `result` 都空，或都没传，这一项跳过。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | 字符串 | 同一次打开里唯一。控件只保存，不拿它查表 |
| `action` | 字符串 | 玩家做了什么。空则不显示这一行 |
| `result` | 字符串 | 这个操作的结果。空则不显示这一段。过长时和事件正文一起在书页内部滚动 |

不要把页码、是否已读、行动点消耗放进这份字典。翻页和滚动由控件自己处理。

```json
{
  "days": [
    {
      "day": 1,
      "events": [
        {
          "id": "tide_notice",
          "title": "潮汐告示",
          "text": "镇口贴出告示。北面的网已经收起，今天先不要出镇。"
        }
      ],
      "actions": [
        {
          "id": "ask_fisher",
          "action": "向老渔夫打听潮汐",
          "result": "他只说今天不要出镇，没有再往下讲。"
        }
      ]
    },
    {
      "day": 2,
      "events": [
        {
          "id": "song_found",
          "title": "遗迹里的船歌",
          "text": "石缝里露出一张受潮的纸。字迹漫漶，仍能认出那是一首船歌。"
        }
      ],
      "actions": [
        {
          "id": "take_song",
          "action": "收好古老的船歌",
          "result": "船歌放进证据。哑伯还没有看见它。"
        }
      ]
    }
  ]
}
```

这条测试数据有两页。第一页标题是 `Day 1`，第二页是 `Day 2`。打开后停在 `Day 2`。第二天的结果写长一些时，只在书页里滚动，不会多出一页。

## 证据栏

入口是 `evidence_modal.apply_engine(data)`，然后 `open()`。控件不读存档，也不使用证据。按下关闭后发出 `closed`。

没有书签，也不再区分剧情物品和普通物品。`items` 给几项就排几格，顺序保持传入顺序。不设数量，也不合并重复项。`apply_engine` 不接收页码。页码由控件自己记；这次刷新后如果超出新的页数，就夹到最后一页。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `items` | 数组 | 一项是一件证据。不是数组就当成没有证据。非对象跳过 |
| `id` | 字符串 | 同一次打开里唯一 |
| `name` | 字符串 | 格子里的名字，也是介绍标题。空则整项跳过 |
| `icon` | 字符串或空 | 资源路径，或 `null`。由控件自己加载，失败就当没有图标，格子里改写名字 |
| `description` | 字符串 | 介绍正文。空则介绍里只有名字 |

```json
{
  "items": [
    {
      "id": "ancient_song",
      "name": "古老的船歌",
      "icon": "res://assets/items/ancient_song.tres",
      "description": "字迹漫漶，隐约可以识读——「向您致敬，深蓝发的神明！蒙您庇佑，我们在波涛之间……」"
    },
    {
      "id": "shell",
      "name": "贝壳",
      "icon": null,
      "description": "证据占位。"
    }
  ]
}
```

船歌会加载图标。贝壳没有图标，格子里写「贝壳」。超过 16 件时才出现第二页，格子数仍是 16。

## 事件弹窗

入口是 `event_modal.apply_engine(data)`，然后 `open()`。控件不读存档，也不调用 `begin()`。点能选的卡先隐藏，发出 `option_chosen(id)`。点关闭只发出 `closed`，不发 `option_chosen`。

试玩里标题用当前事件的 `title`，说明用 `intro`。选项仍按 `A`、`B`、`C` 取 `option(id)`。`blocked_reason(id)` 为空时卡可选，`detail` 写成费用；非空时 `disabled` 为真，`detail` 写成这句原因。控件只显示，不自己算行动点、警戒或证据。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `title` | 字符串 | 居中标题。空则不显示 |
| `text` | 字符串 | 标题下的说明。空则不留说明区。超出在高 160 的区域内滚动 |
| `options` | 数组 | 从左到右的卡。不是数组就当成没有卡。非对象跳过。多于 4 项只取前 4 项。少于 2 项也照显示 |
| `id` | 字符串 | 同一次打开里唯一。随 `option_chosen` 交回 |
| `title` | 字符串 | 卡上的选项名。空则整项跳过 |
| `detail` | 字符串 | 第二行。费用，或不能选的原因。空则不留这一行 |
| `disabled` | 布尔 | 缺省为假。为真时卡变淡，按了没有反应 |

```json
{
  "title": "螺螺发现贝壳",
  "text": "一个孩子在河滩上捡到一枚奇怪的贝壳。它呈螺旋状，表面有淡蓝色纹路，与河里的生物完全不同。",
  "options": [
    {
      "id": "A",
      "title": "让螺螺拿给其他孩子看，一起寻找相似的东西",
      "detail": "2 AP · F +2 · A +1",
      "disabled": false
    },
    {
      "id": "B",
      "title": "先记录贝壳的特征，暂不告诉其他人",
      "detail": "1 AP · F +1 · A +0",
      "disabled": false
    },
    {
      "id": "C",
      "title": "劝螺螺把贝壳放回河里",
      "detail": "行动点不足",
      "disabled": true
    }
  ]
}
```

这条预览有三张卡。C 不能选。选了 A 或 B 只把 id 交回去，不改试玩进度。组件画廊点人物卡时另备三份假数据，字段与上表相同，写在 [scripts/ui/component_gallery.gd](../scripts/ui/component_gallery.gd) 的 `_event_preview`。
