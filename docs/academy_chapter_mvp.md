# 旧学城五回合可玩章节

## 入口与范围

当前正式试玩顺序是 `trial1.tscn` 六天渔村 → 四天集市 → 五天旧学城。集市结束并读完对白后，点击“前往 / 继续旧学城”，或在地图选择旧学城。同一个集市结果继续同一份学城存档；前章重开产生不同结果时分开保存。旧集市存档无需重玩。学城离城后可通过“前往 / 继续羽之森”或地图继续下一章，已有学城存档同样可用。

也可打开 `scenes/academy_chapter.tscn` 按 F6，使用没有前章帮助的独立存档。沿用原场景组件、学城地图背景、角色卡、点击对白/回车推进与固定已完成行动入口。暂时没有学城专属人物插画，使用姓名与职业卡，不借用渔村立绘。

本章不接入独立的 `trail2` 原型。羽之森已可在离城后继续，羽之森结束后可进入王城终章，学城不会交出法器或提前揭示国王动机。

## 故事与通关

开场从二笔装箱时掉落的一张旧港口图开始：同一个地方，新版却称为“内河货站”。墨先生认出自己参与校对的书页，高帽子宣布第五天审议后统一采用新版。玩家先取得完整新旧版本，再查清这是不是有意改书。批次编号只用于核对，不要求玩家记忆。

1. 取得新旧版本并核对年代、对应段落。
2. 取得同批替换销毁记录，以及历史修订规定。
3. 串联同一批次的版本、规定和执行，证明有意删改。
4. 至少完成一种有效成果：分散保存并讲读、审议公开质证、取得正式异议回执。

不要求三位人物全都支持，不以海洋认知分数作为通关阈值。没有完成也可以在第五天离城，保留部分调查成果。比较证据时答错与重试免费，答对后确认才扣原定行动点。

## 人物情感与剧情衔接（2026-10-17）

- 墨先生从“也许是自己漏看”开始；核对后承认轻信统一地名的解释；证据完整后愿意说明校对责任。是否公开署名由玩家选择，匿名留存也体现他的改变。
- 二笔的师姐曾为墨先生抄书，如今被要求签旧稿处理单。二笔由想搬走整箱书，转向按位置保存关键证据，并保护无关抄写员。师姐是背景人物，不增加跑腿任务。
- 高帽子见过档案变成抓人名单，因此担心公开姓名牵连普通人；证据完整后承认不是偶然改错，但登记异议仍不等于官方接受结论。

每个关键行动结束后给出下一步：书页的差异引出换书记录，集中换书引出通知，三份材料合起来证明有计划的删改，再选择传播或登记。行动名称直接说明对象与用途，比较题不要求背术语，答错可免费重试。

离城对白分别反馈读者讨论、审议发言、正式回执及人物处境。只有实际取得旧书，才引用其中普通羽人曾为空中信使的记载，引向羽之森；额外抢救札记才提供旧观测塔的位置。独立调查不会冒出NPC协助，未署名不会替墨先生公开个人证言，暂停协助后只使用已交出的说明。

本轮只调整叙事与提示，保留五天、行动费用、证据条件、认知收益和原有地图、角色卡、立绘对白交互。

## 五日时间安排

每天3 AP，剩余不结转，区域内移动和阅读免费。所有截止时间在开场、侧栏及结束当天确认中显示。

| 日期 | 事件 |
|---|---|
| 第1天 | 发现版本矛盾，公布清理与审议时间 |
| 第2天 | 调查交接记录、规定与人物立场 |
| 第3天末 | 普通旧稿调阅结束 |
| 第4天 | 已知精确目录者可花2 AP定向保全一份旧稿；发言席位申请最后一天 |
| 第4天末 | 未保全的旧版本、交接原件清理；玩家取得的记录不会消失 |
| 第5天 | 定本审议；仍可讲读或提交正式异议，日末离城 |

## 人物与可替代路线

- 墨先生：整理目录后信任达到60，调阅版本；可自愿署名说明自己参与校对的过程。署名留下责任证言，不算额外物证。他担心学生与私人记录受到牵连。
- 二笔：核对交接目录后提供执行记录。第四天可以抢救额外札记，获得指向羽之森旧观测塔的线索，但警戒增加30。
- 高帽子：明确申请来源后，允许正式调阅命令、登记异议。回执证明收到过材料，不意味着官方承认结论。
- 独立调查：公共目录“自行检索→取得新旧版本”，以及“自行检索交接索引→调阅执行记录”，均可替代NPC调阅，主线总成本相同。

合作要求信任≥60、警戒<60、渠道未暂停。警戒达到60时给出下一天末的预警，可以花1 AP保护相应来源、警戒降低20。到期后暂停未来协助；墨先生销毁的是未交出的私人工作记录，玩家材料与实际传播不会被撤回。第五天产生的风险按绝对回合保存，不提前处罚。

## 三种成果与取舍

| 成果 | 行动 | 效果 |
|---|---|---|
| 分散保存与讲读 | 隐去私人身份制作研究副本1 AP，再讲读2 AP | 建立独立保存记录；公众认知+10 |
| 公开质证 | 第四天前申请席位1 AP，第五天质证2 AP | 公众认知+25；高帽子警戒+20；墨先生若署名也+20 |
| 正式异议 | 高帽子入口1 AP、调阅命令1 AP，再选择2 AP单批异议或3 AP完整责任异议 | 取得范围不同的回执；警戒分别+5或+20；不增加公众认知 |

异议两种范围只能选一种。单批异议不会销毁玩家完整调查，完整责任异议也不会自动迫使官方承认。不同成果可兼做，但受15 AP和时限约束。

## 独立实证与认知

完成版本核对后，可花1 AP比对实际携带的渔村证据，或花2 AP核验馆藏旧港器具。两者均为实证补强，不叠加；同一文本的重复抄本不算独立来源。

实证补强后，讲读收益为20，公开质证为35。若先传播再核验，可花1 AP向所有已经接触的读者补充说明，只领取尚未获得的差额。单纯拿到档案、署名、回执不会让未接触材料的公众自动增加认知。

## 集市承接

| 前章成果 | 学城实际效果 |
|---|---|
| 有效读者联络便笺 | 自行检索旧版本目录免1 AP，不凭空提供新证据 |
| 有效客栈引荐信 | 二笔首次核对交接目录免1 AP |
| 公众问答记录 | 审议发言席位申请免1 AP，不替代学城证明 |
| 已发出的商队材料 | 到达绝对回合后才增加学城认知；墨先生预读后首次整理目录免1 AP |
| 仍可使用的集市印刷点 | 学城完成讲读后，最晚第四天花1 AP回传；次日到达，集市认知+10 |

每项折扣只用一次；重复打开、读档不会重复发放。普通帮助已完成后到达的预读反馈，不返还已经花掉的AP。商队收益沿用已发材料的保存值，未到达不算学城传播；仅来件提高认知也不能代替本章调查与成果要求。

回传影响记录在学城离城结果的跨地区账目 `market_belief_after`，供后续地区承接，不改写前章历史存档。前章已确定处罚与未决预警按来源和绝对回合承接。没有前章帮助也能完成全部基本路线。

## 存档与测试

独立规则、叙事、保存和界面分别位于 `scripts/story/academy_chapter_state.gd`、`academy_chapter_story.gd`、`academy_chapter_save.gd` 与 `scripts/ui/academy_chapter.gd`。保存采用校验和、临时文件与有效备份。付费结算先保存再播放对白，读档保留对白位置。损坏时保留原文件，可另存重开。

## 二笔的追查与跨章接应（2026-10-18）

抢救札记仍花2 AP、警戒增加30。达到60时预告下一天末追查；学城花1 AP“安排二笔与师姐避开追查”，保存交接凭据、澄清师姐未参与额外开箱、安排暂避与替代联络，警戒降低20。到期未处理时二笔被停职盘问，师姐接受核查；已有札记、证据、认知及通关成果不撤回。

羽之森公共调查提供两步补救：送出交接凭据1 AP，再安排接应1 AP，可分不同天完成。有可用集市联络或印刷渠道时，第二步免费；不消耗学城帮助的两次额度。只完成第一步尚未恢复安全联系。接应完成后师姐责任澄清、二笔脱离此次追查，但失去工作的事实保留。旧存档从原有警戒和人物状态识别事件。

渠道影响限定为实际经二笔取得记录、完成分散讲读且没有公开质证备用渠道的联系：未接应时不能通过该联系减免羽之森名册调查，仍可自费调查；王城补传学城需要替代联系人或可用集市组织。独立调查、公开质证渠道、已取得的高塔入口与减费资格不受影响。恢复联系不重复发放已使用折扣。

最终报告按提前保护、事后接应、未接应三种情况交代人物处境，不改变四种主结局门槛。王城仅找到替代联系人不等于救出二笔。

专项验证：`tests/er_consequences_tests.gd`；羽之森场景测试包含两步接应与零AP时免费接应按钮。
