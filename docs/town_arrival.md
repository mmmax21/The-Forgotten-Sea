# 第四天上午：正式镇区相遇

运行根目录 project.godot（Godot 4 / F5），从第 1 天正常推进。第 3 天夜间回顾点击进入第 4 天，先显示「第四天上午 · 来到镇区」。读完并确认后：

- 实际所在地从遗迹变为镇区。
- 老渔夫、盐嫂、螺螺、哑伯加入已认识人物，四人当前都在镇区。人物列表可以局部滚动。
- 保留当天 3 AP 与三个空行动槽。抵达属于本次明确指定的剧情，不是计划中的普通移动。
- 可选择人物 → 交谈 → 个人 → 不使用思想卡 → 加入今日计划。每次交谈 1 AP，夜间统一记录。哑伯使用手势/指认交流。
- 手记登记相遇；重看、重复确认不再次执行。重开后人物重新隐藏，直到新一局的第四天事件。

初见只提供姓名、基本身份、可观察到的交流方式。不会提前公开老渔夫孙子的情况、盐嫂丈夫的经历、螺螺未发现的风险，或认定人物已经合作、安全、相信海。基础交谈只更新交流记录，不增加隐藏分数、不制造合作承诺、不赠卡、不开放群体行动。完整人物剧情仍待接入。

本次没有开放自由跨区移动或返回遗迹的正式路线。从镇区查看遗迹对象不会免费移动，也不能隔空调查。若需要调查遗迹中的现有对象，可在第 2～3 天安排。

开发预览配置未改，螺螺在旧预览中的位置仍按独立预览配置处理；正式第四天相遇与预览不是同一份世界状态。

## 文件

- data/events.json：第四天必读时序事件、位置与已认识人物、相遇手记。
- data/targets.json：四人的初见/交流事实和镇区简介；按已发现事实投影。
- data/town_introductions.json：独立的正式基础交谈结果文案，没有引用预览快照。
- scripts/settlement/opening_actions.gd：基础个人无卡交谈接入原夜间行动步骤，检查实际同处镇区。
- tests/town_arrival_tests.gd：相遇、AP、四人动作、隐私、异地、重复执行、预览隔离、重开。
- tests/narrative_tests.gd、tests/demo_tests.gd：按新的第四天事件调整完整流程。最后一天的检查改为第 10 天哑伯交流，确保最后一晚结果先提交再总结。

```

godot --path . --script tests/town_arrival_tests.gd -- --capture

```
