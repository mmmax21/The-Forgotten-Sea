# 羽之森五回合机制设计 v0.1

状态：已按此稿接入五回合可玩版。试玩与当前验证范围见 [羽之森试玩说明](../forest_chapter_mvp.md)。本文保留设计依据与行动排程。

依据：《区域+NPC设定+结局判定.docx》中的羽之森、王城与结局职责；当前六回合渔村、四回合集市、五回合学城的实际机制与离城快照。下述训练场、试验流程、安翼礼、行动点与收益为本次新增设计。

## 1. 本章要解决的问题

核心问题：普通羽人为什么逐渐失去飞行能力？

核心体验：核实过去 → 获得自愿参与与共同支持 → 看见第一次异常 → 跨日复核 → 决定让变化影响谁。

本章可以证明普通羽人曾经飞行、禁令与教育变化先于能力普遍消失，并出现可复核的短暂腾空。不能仅凭一次尝试证明所有现实都由认知任意改变，也不揭晓法器原理、国王动机或外部战争全貌。

基本成功：普通羽人历史已核实，至少一位普通羽人完成有见证的初次尝试与跨日复核。没有海洋认知门槛，不要求所有NPC支持，不要求进入高塔。第5天结束必须离开，失败也保留实际取得的发现。

## 2. 时间、变量和界面

- 五回合，每回合3 AP，剩余不结转。当前连续流程为全局第16—20回合，程序应读取学城 `next_turn`，不能硬编码16。
- 阅读、人物切换、地图切换、查看材料与行动记录免费。
- 海洋认知为羽之森当地公众数值，初始0；前区数值保留在来源账目，不直接复制或平均。
- 三位NPC沿用信任T、警戒A，不新增全局飞行数值。
- 飞行进展由真实行动派生，显示为“历史已核实”“共同支持已形成”“初次现象已记录”“跨日复核已完成”。有记录才显示，不能靠好感度直接跳级。
- 不可用行动置灰，显示缺少的具体条件。预览显示本次与后续成本，例如“首次尝试2 AP；之后另一天复核2 AP”。
- 第5天安翼礼提供公开展示窗口，开场就告知。这里不重复采用烧档案或突然搜查作为章末倒计时。

## 3. 故事骨架

开场：艾尔想在旧训练台张开翅膀，被洛恩劝下。洛恩并非厌恶自由，他担心别人用没有准备的尝试证明理想，最后由家庭承担后果。伊卡恩听到争论，想起小时候从墙上跌落又短暂飞起的经历，却仍称它为梦。

第一层发现：旧运输簿记录普通搬运者承担空中运输；训练场有大量普通尺寸的起落位，并非只供贵族使用。

第二层发现：禁令早期写“不许擅自飞行”，后来的讲义却写“普通羽人不能飞行”。时间顺序与家庭口述一致，但这些仍只能证明社会观念发生过变化，不能单凭文字证明因果。

关键事件：在获得支持与见证后，普通参与者首次出现短暂腾空；隔日复核再次出现，或由另一位同样自愿的普通参与者完成。居民开始重新判断自身能力。

第五天：安翼礼原本要重申地面生活与身份秩序。玩家可提出公开展示新的观察；也可以只保留小范围复核成果，不强迫参与者成为公众人物。

离开：高塔或禁令来源记录出现疯祭司的签署，指向王城。只说明其参与过规定，不直接解释其全部动机。

## 4. 三位NPC

| 人物 | 初始T/A | 作用 | 普通入口 |
|---|---|---|---|
| 艾尔 | 40/30 | 较主动的普通参与者；联系愿意见证的同伴 | 1 AP认真听取经历并约定尝试边界，T+20 |
| 洛恩 | 40/25 | 可以成为普通参与者，也可作为生活经验与邻里信任的来源 | 1 AP讨论家庭顾虑与生活经验，T+20；必须先核实历史，才愿意成为参与者 |
| 伊卡恩 | 35/30 | 提供高塔许可及个人反例；见证特权观念受到挑战 | 1 AP核对童年经历与家族记录，T+25 |

合作条件：T≥60、A<60、未暂停。不通过重复送礼刷信任，普通入口每人一次。

艾尔和洛恩任选一位即可完成基本成功。伊卡恩属于贵族，不能把他的个人飞行当成“普通羽人也能飞”的唯一证明。玩家要更换复核参与者，必须另外取得该普通人的自愿合作，不凭空调换。

第一次选定的参与者保存为 `trial_participant`；复核保存 `replication_participant`。公开前单独说明姓名是否公开及压力，只有具备合作条件、接受公开安排的参与者才上场。不是玩家拖着NPC去证明观点。

## 5. 证据与用途

| 标识 | 材料 | 来源与用途 |
|---|---|---|
| roster | 普通羽人空运名册 | 本地旧记录；明确职业、身份与飞行任务，含沿海航线条目 |
| platform | 旧训练场测绘与结构记录 | 本地遗迹实物；与名册交叉验证普通羽人使用过起落设施 |
| history_verified | 普通羽人飞行史核验 | roster＋platform；不是新增来源 |
| ban | 历次禁飞规定与讲义对照 | 观察“不许”如何变成“不能”；含可继续追查的签署编号 |
| restriction_trace | 禁令时间线核对 | ban＋history_verified；说明先后关系，不声称单凭相关性证明因果 |
| first_observation | 初次尝试观察记录 | 记录参与者、准备、见证、时间及腾空现象 |
| replication | 跨日复核记录 | 保存第二日期与见证信息；重复打印不能替代第二次观察 |
| tower_observation | 高塔方向与远方水面观察 | 可步行登塔；记录方向、地貌与多名现场见证，不要求先恢复长距离飞行 |
| signature | 禁令签署来源 | 由高塔告示原件或正式查询取得，指向疯祭司 |

海洋与飞行证据不混算。同一篇学城旧史被本地讲义转抄，只是来源联系，不算独立物证。梦境提供调查方向，不独立提供海洋认知加成。

第一版不加入隐藏的试验成功率。未准备好时“首次尝试”置灰，告诉玩家缺什么；不通过无法预知的失败消耗玩家的2 AP。满足已公布条件后出现对应现象，但只承诺短暂腾空，不承诺立刻恢复长距离飞行。

签署查询的两个入口共用同一份材料，已有signature后不能重复收费领取。完整责任异议比单批回执多提供一段命令签署与执行责任的追问，可保存为王城对话依据，不自动解除禁令。

## 7. 风险和截止规则

- 试验准备与小范围见证不自动招致惩罚。
- 每次有记录的飞行尝试使实际参与者A+5；公开展示额外A+25。
- A达到60时预告下一回合末的压力事件：暂停未来参与或家庭联络，已有观察记录、已发生的腾空与已送达消息不删除。
- 第5天公开导致的风险保存为离林后的待处理事件，不能提前在第五天处罚。角色是否继续支持与已经发生的历史事实分开记录。
- 保护行动减少具体人物压力，不清除公众的记忆，也不把具名事件变回匿名。
- 高塔开放是地点状态。已经进入后不会因伊卡恩日后暂停帮助而被“传送出去”；尚未取得许可时，仍可走废弃入口。
- 最晚第4天首次尝试、第5天复核可基本通关；但第5天复核2 AP和公开展示2 AP不能同一天完成。想公开，必须第4天前完成复核。
- 废弃入口耗时更多、但不绑定贵族合作；不随机追加坠落或死亡判定。

## 8. 海洋认知收益

飞行试验和历史核验本身不直接增加海洋认知。只有向真实接收者说明海洋相关依据后才结算。

| 已核实依据 | 小范围说明（1 AP） | 安翼礼公开说明（包含于2 AP展示） |
|---|---:|---:|
| 本地名册与训练场核实，沿海航线可信 | +5 | +10 |
| 本地依据＋前区独立实证已比对 | +10 | +20 |
| 本地依据＋高塔水面观察 | +15 | +25 |
| 本地依据＋高塔观察＋前区独立实证 | +20 | +30 |

每格是该渠道累计收益上限，各档不相加。公开与小范围代表不同接收群体，可以分别结算；同一批读者重复讲相同内容不重复加分。先讲读再补强，需要执行补充说明；一次补充可覆盖已接触的两个群体，仅发放各自未获得的差额。

公开展示主要证明普通羽人能力可能恢复；其中海洋说明必须明确引用已核实的航线或水面观察，不能说“他飞起来了，所以一定有海”。玩家可以有飞行成功、海洋认知0的离林结果，仍然保留有意义的社会改变。

## 9. 前章承接：对齐当前学城快照

| 当前字段 | 羽之森作用 | 限制 |
|---|---|---|
| channels.independent_archive | roster行动免1 AP | 旧史给出可查编号，不能直接给予history_verified |
| channels.public_record | witnesses行动免1 AP | 仍需核实本地历史，并有自愿参与者 |
| findings.file_limited | 正式查询signature时免本地申请登记 | 不解除禁令、不提高NPC信任 |
| findings.file_full | 同样免登记，并开放责任范围追问 | 与单批回执不叠加；不自动获得高塔观察 |
| findings.rescue_extra | 提供废弃入口精确位置，并使tower_enter从2 AP降为1 AP | 不自动进入、不自动取得观察 |
| evidence.museum且holder=player | 可用于cross_region的独立物证核验 | 文本抄本不能冒充馆藏实证 |
| origin内实际随身渔村材料 | 可用于cross_region | 寄存物不能瞬移；同源物件及抄本不叠加 |

总行动折扣上限建议为2 AP；进入时显示可用帮助，玩家在行动确认时主动使用，避免自动消耗在不需要的路线。免费取得的入口位置信息不扣折扣额度；从2 AP减为1 AP消耗1额度。额度用完仍可按正常费用行动，提示清楚。

读取学城next_turn决定入林时间。pending_penalty只在首回合兑现一次。学城warnings是墨先生、二笔、高帽子的个人后果，不能全部自动转换成羽之森扣AP：到期时更新对应联系人状态并显示来信，保留已传播成果。只有明确记录的跨地区查验处罚才影响行动点。

旧存档缺少帮助时采用无帮助默认状态。每次新局有独立来源身份；同一学城结果重新进入，应恢复同一份羽之森进度。

## 10. 已排程的代表路线

以下排程已按行动成本、前置条件、每天3 AP和跨日复核规则核对通过；这不是实际游戏运行测试。均不使用前章折扣、也无额外查验处罚。每格按执行顺序排列；同一天不得超过3 AP。

### A. 稳妥复核，10 AP

| 日期 | 行动 | AP |
|---|---|---:|
| 1 | 名册、训练场、核实历史 | 3 |
| 2 | 艾尔入口、联系见证者、准备低台 | 3 |
| 3 | 首次尝试 | 2 |
| 4 | 跨日复核 | 2 |
| 5 | 可处理支线，或直接离林 | 0 |

结果：普通羽人飞行现象已复核，基本成功；未传播海洋发现时认知0。保留5 AP选做其他内容。

### B. 禁令调查＋公开展示＋保护参与者，15 AP

| 日期 | 行动 | AP |
|---|---|---:|
| 1 | 名册、训练场、核实历史 | 3 |
| 2 | 艾尔入口、联系见证者、准备低台 | 3 |
| 3 | 首次尝试、查阅禁飞规定 | 3 |
| 4 | 跨日复核、核对禁令时间线 | 3 |
| 5 | 安翼礼公开展示、保护艾尔及家属 | 3 |

结果：基本成功、制度变化线索、公众见证；基础海洋认知10。艾尔A从30到40，再因公开到65，保护后45，解除未到期压力。没有高塔观察。

### C. 伊卡恩高塔路线＋小范围海洋说明，15 AP

| 日期 | 行动 | AP |
|---|---|---:|
| 1 | 名册、训练场、核实历史 | 3 |
| 2 | 艾尔入口、联系见证者、准备低台 | 3 |
| 3 | 首次尝试、伊卡恩入口 | 3 |
| 4 | 跨日复核、伊卡恩带领进入高塔 | 3 |
| 5 | 高塔观察、小范围海洋说明、保护参与者（或保留此点） | 3 |

结果：基本成功、高塔水面观察与禁令签署；海洋认知15。不具备公开展示成果。最后1 AP的保护不是强制要求，当前小范围路线通常未触发警戒。

### D. 不依赖伊卡恩的高塔路线，15 AP

| 日期 | 行动 | AP |
|---|---|---:|
| 1 | 名册、训练场、核实历史 | 3 |
| 2 | 艾尔入口、联系见证者、准备低台 | 3 |
| 3 | 首次尝试、定位废弃入口 | 3 |
| 4 | 从废弃入口进入、高塔观察 | 3 |
| 5 | 跨日复核、小范围海洋说明 | 3 |

结果与高塔基本路线相近，但时间排满，无法保护参与者或公开展示。跨日复核可以间隔一天；高塔由步行进入，不要求先恢复长距离飞行。

艾尔可替换为洛恩入口，核心行动成本不变。普通参与者入口安排在核实历史之后，符合洛恩的参与条件。

## 11. 离林成果与终局接口

离林记录至少包括：

- success、next_turn、当地belief_local；前区认知账目分别保留。
- 证据及来源：历史核实、禁令时间线、高塔观察、签署来源、独立实证。
- 试验日志：两次日期、参与者、见证、现象；不存在记录则不导出飞行成功。
- 社会成果：普通羽人能力已复核、是否公开展示、是否出现第二位普通参与者。
- 两个传播渠道的已结算收益；差额补充记录。
- NPC信任、警戒、未来协助状态与未决风险；绝对到期回合。
- 使用过的前章帮助及剩余折扣额度，防止重入刷收益。

海回归：海洋传播贡献参与后续跨地区判定，具体全局阈值留待王城统一验证。

王国获得解放：普通羽人获得能力与自主行动的实际成果，以及对血统特权的公开挑战，都可作为削弱控制体系的依据；不要求海洋已经回来。

新的王：需要王城中取得法器并主动接管，羽之森不自动授予。

遗忘重临：不能仅因羽之森认知低就判失败；应结合全局传播、渠道与最终选择。

## 12. 制作顺序与验收

1. 独立状态与五回合存档、学城离城入口、原有地图和角色卡交互。
2. 10 AP基础试验路线与逐步引导。
3. 第五天公开展示、个人预警和保护。
4. 高塔双入口、禁令线与海洋传播。
5. 学城成果折扣、来源核验与跨地区后果。
6. 四条路线、旧存档默认值、读档中断与界面检查。

必须验证：首次与复核不能同日；贵族飞行不能替代普通参与者；没有证据和见证时按钮准确置灰；第一次试验不会直接通关；公开只在第五天；已发生现象不因关系恶化撤回；旧物来源不重复计算；档位加成只补差额；折扣总计不超过2 AP；重进不重复发放；已暂停协助不影响保存的观察；未通关仍能正常离林；后续结局不提前触发。
