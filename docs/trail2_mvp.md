# Trail2：十五天策略叙事 MVP

## 启动

在 Godot 中打开 `scenes/trail2.tscn`，按 **F6** 运行当前场景。项目原有 F5 默认入口保持不变。

启动会恢复 Trail2 存档；设置中可保存、读取最近进度、确认重新开始。底部显示保存结果。旧版渔村与集市存档会升级，不重置AP或重新发奖励。

## 操作

- 左侧选当前地区三位人物，中间行动列表可滚动。点行动查看条件、成本、预期变化，再确认执行。
- 渔村“前往遗迹 · 1 AP”、集市“核验材料／查看禁令”、学城“档案、观测与法器调查”是自主调查入口。
- 顶部材料页查看持有人、来源与安排；渔村可在此制作记录、取回材料。
- 集市选刀郎处理复制与投放，选阿香处理联系人与递送，自主调查区可自行抄写、取回未用副本。
- 结束当天会先提示窗口和风险；剩余AP作废。第5、10天结算后，在离场报告中前往下一区域。
- 第15天仍可正常行动；结束后结算。取得法器时再选择处置，接管无有效渠道时不可选。终局可反复查看。
- 查看信息、地图和同地切换人物不消耗AP。渔村与遗迹每次单程移动消耗1 AP，确认后扣费；不足1 AP不能移动。同一地点不重复收费。跨区域从第6/11天的AP扣除1点（可与处罚叠加）。遗迹中不能远程与村民行动，返回村庄也要1 AP；第5天不能再进入遗迹，但可以从遗迹返回。旧区域托管材料不会自动进入背包。

## 已实现的范围

渔村：三条人物入口与遗迹调查、粮食、逐人T/A/知情、展示、同源记录、批量托管、传播、撤回、巡查、预警与离场报告。

集市：普通帮助/专业说服互斥、三类独立底稿、固定P1/P2配方、单份/小批/大批、明确预留副本、即时本地投放、商队待发、具名赶印与修复、暴露和旧/新址、预告检查、一次转移、关闭没收与取消、公开回应及持续渠道。

旧学城：前期入口、三人专业替代、自主定位与调阅、同批P3证据链、14日保全、馆藏海洋补证、跨日P4观测、公开质证/署名/回应/留档、一次分散传播、次日到达的补发、法器4步调查。

终局：海回归和制度突破分别保存；主动接管优先，否则海回归、解放、遗忘重临。包含法器处置、九人贡献与后果、16日未决预警，不额外提供可操作天数。

存档：独立 `user://trail2_v1.json`（文件名保持稳定，内部格式现为版本4），校验、临时写入替换、上一份有效备份、失败提示；兼容版本1/2/3；旧存档保留AP，按原查看地点恢复位置，不追扣历史路费。旧原型存档不受影响。

## 一个可重复的完整验证路线（含剧透）

| 日期 | 行动 |
|---|---|
| 1 | 盐嫂送粮、倾听；哑伯修整 |
| 2 | 安置家人；移动到遗迹（1 AP） |
| 3 | 勘察、清障、搜查 |
| 4 | 返回渔村（1 AP）；哑伯辨认、查看盐嫂遗物 |
| 5 | 自行制作遗物记录；盐嫂安排传播；结束并前往集市 |
| 6 | 抵达扣1 AP；刀郎普通帮助 |
| 7 | 取得文本、对照禁令形成P2、刀郎保护信息 |
| 8 | 小批复制P2、刀郎小范围投放 |
| 9 | 钱伯普通帮助、取得古物材料 |
| 10 | 渔村物证与古物记录对照P1；结束前往旧学城 |
| 11 | 抵达扣1 AP；高帽子专业入口、取得命令 |
| 12 | 墨先生普通帮助、按编号取得执行记录、制度追溯P3 |
| 13 | 墨先生分散传播、审核署名 |
| 14 | 取得旧观测记录、首次观测 |
| 15 | 再次观测、公开质证；结束 |

渔村五天含往返正好15 AP。该路线使用实际行动贯通三地，同时达成海回归和制度突破。它是回归样例，不是唯一解或最低AP证明。任一地区未完成目标也可继续。

## 表现层说明

沿用 main 的组件与布局，并复用现有三地及遗迹背景和地图地点。渔村使用已有立绘；集市、学城六位人物暂以姓名卡显示。渔村已加入开场、动态人物回应、关键行动短对白、遗迹阶段描述、每日过渡和按实际结果生成的离村告别。规则条件在确认弹窗，行动后的数值变化在右侧，底部对白框专注剧情。已完成行动折叠，安置窗口优先显示，滚动列表有提示；无新配音。材料内容绑定为明确的演示来源与修订批次A，保证配方可核验；未把任意两份同源材料当成独立证据。

体验回归覆盖动态对白、安置首屏显示、折叠与滚动提示、两种窗口尺寸的正文与按钮边界，以及真实场景五天含移动路线。

自动化通过不等于完整视觉试玩或穷举平衡。当前电脑的界面自动化未能启动，因此尚未完成截图级视觉验收。

## 盐嫂的高风险捷径

首次见面可用1 AP「追问丈夫遗物」，获得同一份确认遗物，信任−10、警戒＋15并知情。与「查看遗物」互斥，材料不能重复取得。初始直接逼问后为信任30、警戒65，第2天末仍处于高危便告密，第3天少1 AP；遗物保留。

逼问后「送粮」改称「赔礼并送粮」（1 AP＋1粮食，信任＋15），「倾听」改称「倾听她的顾虑」（1 AP，需送粮，信任＋15、警戒＋5）。完整补救到信任60，解除预警但仍沉默。安置沿用2 AP＋1粮食、警戒−20与第3天末截止；巡查仍可能使警戒再次达到60。普通路线倾听仍为信任＋10。原有撤回协助请求的补救仍有效，但会放弃本阶段协助资格。

`tests/trail2_reporting_tests.gd` 覆盖展示告密、逼问告密、补救、互斥领取与失败不扣费。
