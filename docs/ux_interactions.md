人物卡点开后的对话是当场进行的。规划里已有的「选人 → 交谈或调查 → 加入今日计划 → 夜间结算」是另一条流程，不在本文改动。

## 对话

从人物栏进入。一次只开一个对话界面。打开后盖住底层，底层不再接收点击，人物介绍收起。

界面分区见组件文档的「对话界面」：左 NPC、右玩家、中缝按钮、下方文字框。说话的一侧保持亮度并向中缝靠一点，另一侧压暗。

### 阶段

界面只处在下面四个阶段之一。前一个阶段的按钮在进入下一个阶段时收起。

| 阶段 | 中缝 | 文字框 | 离开 |
| --- | --- | --- | --- |
| 旁白 | 空 | NPC 开场，一段一段显示 | 最后一段已经显示在框里 |
| 动词 | 交谈、调查、取消 | 停在旁白最后一段 | 点其中一个按钮，或按 ESC |
| 选项 | 该动词下的具体选项 | 仍停在旁白最后一段 | 点中一条选项 |
| 对白 | 空 | 两人的预设对白，一段一段显示 | 最后一段显示之后，再推进一次 |

旁白和对白都是整段出现，不逐字打出。推进一次只换下一段，不跳到末尾。

### 步骤

1. 在人物栏上，指针按下并在同一张卡上松开，算一次单击。拖出卡片不算。置灰的卡不打开对话。
2. 调用方把这个 NPC 的对话数据交给界面并打开。左侧用该 NPC 的肖像和名字，右侧用玩家。
3. 进入旁白。左侧亮起。`opening` 按顺序放入文字框。框里已有文字时，单击文字框或按回车，换成下一段。
4. 旁白最后一段留在文字框里，进入动词。三个按钮同时出现：交谈、调查、取消。取消等同 ESC。
5. 取消或 ESC：发出 `cancelled`，关闭界面。不扣行动点，不触发效果。
6. 交谈或调查：收起三个按钮，进入选项。中缝只列出该动词的具体选项，文案用 `label`。另一动词的选项不出现。
7. 点中一条选项后，收起选项，进入对白。`lines` 按顺序显示。`speaker` 为 `npc` 时左侧亮起，为 `player` 时右侧亮起。
8. 对白的推进和旁白相同：单击文字框，或按回车，显示下一段。
9. 最后一段先留在框里。再单击文字框或再按一次回车，才算这段对白结束。
10. 界面关闭，发出 `resolved(option_id)`。调用方接着扣该选项的行动点，再执行该选项绑定的效果。效果可以是数值变化、获得物品，或后续事件。界面自己不执行这三件事。

### 输入

| 操作 | 旁白 | 动词 | 选项 | 对白 |
| --- | --- | --- | --- | --- |
| 单击文字框 | 下一段；已是最后一段则进入动词 | 无 | 无 | 下一段；已是最后一段则结束 |
| 回车 | 与单击文字框相同 | 无 | 无 | 与单击文字框相同 |
| ESC | 关闭，视为取消 | 关闭，视为取消 | 关闭，视为取消 | 不关闭 |
| 单击肖像或中缝空白 | 无 | 无 | 无 | 无 |

对白已经开始就不接受取消。玩家已经选中具体选项，这段交互要播完才结算。

选项阶段按 ESC 同样视为取消：不扣点，不触发效果。选项列表上没有返回动词的按钮。

### 结算

行动点挂在具体选项上，不挂在「交谈」或「调查」这两个动词上。调用方在组数据时就去掉付不起的选项，界面不读剩余点数。

- 只看完旁白后取消：不扣点。
- 进入选项后取消：不扣点。
- 对白播完：扣这一条选项的点数，再触发它的效果。
- 同一次打开只结算一次。关闭之后的重复信号不再扣点。

动词下一条可选选项都没有时，该按钮仍留在中缝里，但是置灰，点了停留在动词阶段。两个动词都置灰时，只能取消离开。
