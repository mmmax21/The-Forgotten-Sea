# 交互

这里维护玩家实际怎么操作。控件的外观、数据和信号写在 [ui_components.md](ui_components.md)。嵌套入参和测试 JSON 写在 [data_formats.md](data_formats.md)。改步骤时一起改：界面结构放组件文档，先后顺序和结算放这里，字段放格式文档。

下文保留早期通用交互约定。当前渔村—遗迹章节已实现的流程以 [运行说明](ruins_runtime.md) 为准；当前使用具体行动按钮，不采用下面的通用“交谈／调查”四阶段选择器。

人物卡点开后的对话是当场进行的。规划里已有的「选人 → 交谈或调查 → 加入今日计划 → 夜间结算」是另一条流程，不在本文改动。

## 对话

从人物栏进入。一次只开一个对话界面。打开后盖住底层，底层不再接收点击，人物介绍收起。

界面分区见组件文档的「对话界面」：左 NPC、右玩家、中缝按钮、下方文字框。说话的一侧保持亮度并向中缝靠一点，另一侧压暗。

### 阶段

界面只处在下面四个阶段之一。前一个阶段的按钮在进入下一个阶段时收起。

| 阶段 | 中缝 | 文字框 | 离开 |
| --- | --- | --- | --- |
| 旁白 | 空 | NPC 开场，一段一段显示 | 最后一段已经显示在框里 |
| 动词 | 交谈、调查、取消 | 停在旁白最后一段 | 点其中一个按钮，或按 ESC |
| 选项 | 该动词下的具体选项 | 仍停在旁白最后一段 | 点中一条选项 |
| 对白 | 空 | 两人的预设对白，一段一段显示 | 最后一段显示之后，再推进一次 |

旁白和对白都是整段出现，不逐字打出。推进一次只换下一段，不跳到末尾。

### 步骤

1. 在人物栏上，指针按下并在同一张卡上松开，算一次单击。拖出卡片不算。置灰的卡不打开对话。
2. 调用方把这个 NPC 的对话数据交给界面并打开。左侧用该 NPC 的肖像和名字，右侧用玩家。
3. 进入旁白。左侧亮起。`opening` 按顺序放入文字框。框里已有文字时，单击文字框或按回车，换成下一段。
4. 旁白最后一段留在文字框里，进入动词。三个按钮同时出现：交谈、调查、取消。取消等同 ESC。
5. 取消或 ESC：发出 `cancelled`，关闭界面。不扣行动点，不触发效果。
6. 交谈或调查：收起三个按钮，进入选项。中缝只列出该动词的具体选项，文案用 `label`。另一动词的选项不出现。
7. 点中一条选项后，收起选项，进入对白。`lines` 按顺序显示。`speaker` 为 `npc` 时左侧亮起，为 `player` 时右侧亮起。
8. 对白的推进和旁白相同：单击文字框，或按回车，显示下一段。
9. 最后一段先留在框里。再单击文字框或再按一次回车，才算这段对白结束。
10. 界面关闭，发出 `resolved(option_id)`。调用方接着扣该选项的行动点，再执行该选项绑定的效果。效果可以是数值变化、获得物品，或后续事件。界面自己不执行这三件事。

### 输入

| 操作 | 旁白 | 动词 | 选项 | 对白 |
| --- | --- | --- | --- | --- |
| 单击文字框 | 下一段；已是最后一段则进入动词 | 无 | 无 | 下一段；已是最后一段则结束 |
| 回车 | 与单击文字框相同 | 无 | 无 | 与单击文字框相同 |
| ESC | 关闭，视为取消 | 关闭，视为取消 | 关闭，视为取消 | 不关闭 |
| 单击肖像或中缝空白 | 无 | 无 | 无 | 无 |

对白已经开始就不接受取消。玩家已经选中具体选项，这段交互要播完才结算。

选项阶段按 ESC 同样视为取消：不扣点，不触发效果。选项列表上没有返回动词的按钮。

### 结算

行动点挂在具体选项上，不挂在「交谈」或「调查」这两个动词上。调用方在组数据时就去掉付不起的选项，界面不读剩余点数。

- 只看完旁白后取消：不扣点。
- 进入选项后取消：不扣点。
- 对白播完：扣这一条选项的点数，再触发它的效果。
- 同一次打开只结算一次。关闭之后的重复信号不再扣点。

动词下一条可选选项都没有时，该按钮仍留在中缝里，但是置灰，点了停留在动词阶段。两个动词都置灰时，只能取消离开。

### 待定

- 对白进行中还没有中断。若以后允许中途离开，要单独写明离开时扣不扣点。
- 具体选项的点数和效果正文还没有数据文件。界面只上抛 `option_id`。

## 小地图

右下角三个圆钮。悬停只发生在圆内，方框四角不算。两个小钮叠在指南针上，重叠处算小钮。

悬停时换成合图的中格，按下时换成右格。指南针和小钮都是这样。指针离开就回到常规。

按下只把 id 交给调用方，控件自己不打开界面。

| id | 按下之后 |
| --- | --- |
| `compass` | 调用方打开大地图 |
| `gather` | 上侧小钮，纸心是「集」。剧情入口打开确认弹窗。确认后：当前地区每个居民的支持度增加，全局警戒值增加，行动点 -1 |
| `hide` | 下侧小钮，纸心是「隐」。剧情入口打开确认弹窗。确认后：全局警戒值下降，支持度不变，行动点 -1 |

增减量的默认值在 `data/region_stance.json`。弹窗正文来自 `confirm_copy`，里面写明变化前后的支持度、警戒值和行动点。

1. 按下「集」或「隐」。
2. 确认弹窗出现。取消：三个数都不变。
3. 按下确认：付得起行动点，并且至少有一个数会变，才写入新数值并扣 1 AP。顶栏随即刷新。
4. 行动点不足，或警戒值已经到下限、隐藏不会再降：弹窗说明原因。再按确认也不会结算。

## 确认弹窗

从调用方打开。全屏遮罩完全透明，背后的控件点不到。点遮罩不关闭。

「确认」和「取消」都会先关掉弹窗。确认再走传入的确认方法，取消再走传入的取消方法。方法没传就只关闭。没有右上角关闭钮。

## 大地图

从指南针打开。遮罩挡住底层点击。点遮罩不关闭。点纸面右上的关闭按钮后，界面隐藏，发出 `closed`。

有海或无海、每个地点能否前往，在打开前由调用方传入。字段见 [data_formats.md](data_formats.md)。

### 悬停

指针进入能前往地点的椭圆时，椭圆外缘出现半透明米黄光圈。光圈的宽高比椭圆大约大 16。指针在椭圆外的方框四角上，不出现光圈。离开椭圆，光圈消失。同一时间只亮指针下面的那一个。

小地图三个圆钮的变暗，和大地图这圈光是两件事。

### 能否前往

能前往的地点保持现在的样子：显示地名，椭圆内悬停出光圈，椭圆内接住点击。点中后不立刻离开，地图自己的确认弹窗先写明目的地和要扣的行动点。取消留在地图上。确认后才发出 `place_chosen` 并关闭地图。剧情入口这时才改所在地：遗迹去遗迹，渔村去哑伯住处。已经在当地，或行动点不够时，确认也不会离开。

不能前往的地点盖上遮挡物。地名不显示。没有光圈。椭圆内点不中，遮挡物上的点击也没有反应。遮挡物停在那里，不跟指针变化。

没传 `places` 时六地都能前往。传了这份名单却没写到的地点，按不能前往处理。

## 物品栏

组件画廊里，点顶栏「物品」打开。遮罩挡住底层点击。点遮罩不关闭。字段见 [data_formats.md](data_formats.md)。画廊这一版用弹窗自带的预览物品。

1. 点左侧书签，在「剧情」和「普通」之间切换。换过去回到第 1 页。
2. 点左箭头或右箭头翻页。第一页左箭头无效，最后一页右箭头无效。这一侧不足或刚好 16 件时，两枚都无效。格子仍是 16 个。
3. 指针进入有物品的格子，右侧出现名字和描述。描述超出时，滚轮停在格子上可在介绍里滚动。离开格子，介绍消失。空格没有介绍。单击格子不使用物品。
4. 点右上角关闭后界面隐藏，发出 `closed`。
