# 界面操作

顶栏只发出按钮 id。打开哪一张弹窗由调用方决定。组件画廊里的对应关系见 [data_formats.md](data_formats.md)。点遮罩都不关闭。已经有一张弹窗开着时，顶栏按钮不会再叠开一层。

## 手记

从顶栏「手记」打开。遮罩挡住底层点击。点遮罩不关闭。

1. 打开后停在最后一天。页首是 `Day N`。
2. 书页先列「当日事件」，再列「玩家操作」。操作下面是这次操作的结果。
3. 文字超出书页时，在书页内部滚动。翻到另一天时滚回页顶。
4. 点左箭头看前一天，点右箭头看后一天。第一天左箭头无效，最后一天右箭头无效。翻页时播放书页动画。
5. 点右上角关闭后界面隐藏，发出 `closed`。

## 证据栏

从顶栏「证据」打开。遮罩挡住底层点击。点遮罩不关闭。没有书签。

1. 证据按传入顺序排进 4×4。超过 16 件才翻页。
2. 点左箭头或右箭头翻页。第一页左箭头无效，最后一页右箭头无效。不足或刚好 16 件时，两枚都无效。格子仍是 16 个。
3. 指针进入有证据的格子，右侧出现名字和描述。描述超出时，滚轮停在格子上可在介绍里滚动。离开格子，介绍消失。空格没有介绍。单击格子不使用证据。
4. 点右上角关闭后界面隐藏，发出 `closed`。

## 事件弹窗

试玩里，开场对白播完后打开。组件画廊里，点能选的人物卡打开，用的是画廊里的假数据，选卡和关闭都不改进度。遮罩挡住底层点击。点遮罩不关闭。收尾阶段的整理笔记、谨慎收尾和结束本回合不在这张弹窗里。

1. 点一张能选的卡。弹窗先关掉，发出 `option_chosen`。试玩再走原来的 `begin`，成功才播放结果对白。
2. 点不能选的卡。弹窗留着，不发信号。
3. 点右上角关闭。弹窗关掉，只发 `closed`。这一次不算选择，不扣行动点。
4. 关闭之后，底部文字框写「点击此处，查看可以采取的行动」。再点文字框，用当前选项重新打开。

## 状态与设置

「状态」打开通知。点遮罩不关闭，点右上角关闭。

「设置」打开原来的设置窗口。重新开始需要再确认一次。
