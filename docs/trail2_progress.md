# Trail2 MVP 分步进度

独立入口：`scenes/trail2.tscn`。在 Godot 打开该场景后按 F6；项目默认入口未修改。

## 第一步：界面骨架（用户已确认）

复用 main 的组件和布局，加入渔村三人、仓库入口、期限说明与初始资源。

## 第二步：当天自由行动（用户已确认）

- 人物与仓库共14个基础行动，执行前显示条件、成本、确定效果与行动后状态。
- 免费查看、切换人物或地点；取消预览不扣费；确认时重新检查条件。
- AP、粮食、一次性奖励、入口共享、材料来源和持有人、信任警戒及知情状态。
- 动态人物状态、材料清单与行动手记；设置中可确认重新试玩。
- 规则集中在 `scripts/story/trail2_state.gd`，界面在 `scripts/ui/trail2.gd`。

第二步验收时仅开放第1天；当前跨日能力见第三步。

验收路线（每条先重新试玩）：

1. 送粮 → 倾听 → 修整旧物：剩余0 AP、1粮食；盐嫂T65/A55，哑伯T65/A40，双方未知情。
2. 勘察 → 清障 → 搜查：剩余0 AP、2粮食；玩家取得未确认碎片。
3. 听见闻 → 取回遗落物品 → 清障：螺螺T60/A20，未知情，入口已清理。
4. 送粮 → 倾听 → 查看遗物：盐嫂T65/A65，知情、沉默；已取得的遗物保留。

Godot 无界面回归：`--headless --path . --script tests/trail2_tests.gd`。

## 第三步：五天时间与风险结算（用户已确认）

- 结束当天前预览剩余AP作废、今晚到期预警、即将关闭的窗口和次日AP。
- 确认后先复查预警、关闭机会，再恢复次日AP和执行日初固定事件。取消不改变状态。
- 第2天提示巡查；第3天开始仅当时知情者A＋10一次；后来知情不追补。
- 第3天结束关闭安置，第4天结束关闭仓库；已有碎片第5天仍能辨认。
- 高危预警于次日末到期，持续高危不刷新；解除后再次高危才生成新窗口。
- 渔村首次告密仅产生一次次日−1 AP处罚，不牵连未参与人物或没收全部材料。
- 第5天结算后锁定本地行动，保留材料、人物、未决预警和处罚的内存快照。第6天暂不开放，未实现磁盘存档。
- 右侧显示实时期限与风险；结束后可查看阶段记录。旧日期的重复确认不推进第二次。

跨日试玩路线：

1. 第1天送粮→倾听→修整旧物。
2. 第2天安置家人→勘察入口。
3. 第3天开始双方未知情，巡查不加警戒；清障→搜查→辨认，哑伯最终T65/A50。
4. 第4天查看遗物，盐嫂最终T65/A45；可提前结束。
5. 第5天结束，阶段记录应有两份确认原物、家人已安置，不能继续本地行动。制作记录和传播尚未接入，不是完整13 AP路线。

自动回归覆盖跨日、知情时点、窗口关闭、重复结算、预警解除与重入、跨区未决期限。当前基础行动不会自然产生低信任知情高警戒组合，告密边界使用明确构造的状态测试；待展示证据接入后再验证完整玩家路线。

## 第四步：材料、协助与渔村离场（用户已确认）

- 顶栏“材料”中可自行制作记录（2 AP）、请抄写摊制作（1 AP＋1粮食）、免费取回托付材料。原物与记录同源，持有人分别记录。
- 人物行动列表新增展示、保管（仅盐嫂和哑伯）、传播（仅盐嫂）。展示每人一次，原物与记录都可使用。
- 保管可勾选两件原物，一次交接共1 AP；每人最多两件。所有材料共用一个持有人账本，远处材料不能直接制作记录或展示。
- 传播付费后先记待执行；第5天先处理告密，再复查保管和传播。原物可另行付费同时登记保管与传播，持有人仍唯一。
- 普通取回明确取消所选材料关联的所有安排，不退AP或回滚警戒；盐嫂专属撤回额外收费降警戒，归还她手中材料并撤销本阶段协助资格。
- 无效保管和传播材料在离场退还；有效传播生成独立历史事件，暂停安排不会后台恢复。
- 离场报告分别展示基本／进阶目标、随身独立来源、带走与留下的材料、家人安置、合作、未决预警和处罚、后续集市入口。结构化成果与材料快照保留供后续使用。

已验证完整13 AP路线：按第三步路线完成到第4天查看遗物，随后在材料页自己制作遗物记录（2 AP）；第5天选盐嫂→安排传播→选遗物记录（1 AP），剩余2 AP。结束后两份原物随身、记录留给盐嫂、T65/A55、两项目标完成。

展示接入后，告密与补救已使用真实玩家行动路线测试；另覆盖记录展示、重复展示拒绝、两件托管、远处材料不可用、普通及专属撤回、暂停材料退还、多选UI与取消预览。

第四步结束时未开放磁盘存档；现已接入，见第五步。集市、旧学城与终局尚未开放。

## 第五步：存档与恢复（用户已确认）

- 独立存档 `user://trail2_v1.json`，版本1；不读取或覆盖旧原型存档。
- 确认行动、材料操作、每日结算、重新开始及切换查看对象后保存；预览不执行行动。界面底部显示保存成功、失败或备份恢复信息。
- 启动自动读取；设置提供保存重试、读取最近存档（先确认）、重新开始（先确认）。恢复选择对象及最近显示文字，不恢复未确认弹窗。
- 完整保存日期/AP/粮食、人物T/A/知情/预警、一次性完成标记、原物和记录账本、保管和传播、历史事件、离场快照、结果与处罚是否已执行。
- 读取不推进日期、不重发材料、不重复巡查或离场发布。JSON整数类型恢复后与原状态一致。
- 保存先写临时文件并验证，再替换主档；保留上一份有效备份。主档损坏可恢复备份，界面明确提示回退。
- 主档和备份均不可读时保留文件并暂停自动保存，不以初始状态静默覆盖。用户可重试读取或明确确认重新开始。
- 回归使用独立 `/tmp` 目录，不触碰玩家存档；覆盖实际场景销毁重建、未确认预览、全部状态往返、协助、处罚、离场、损坏/版本错误、写入失败及重新开始取消。

试玩验收：执行一次行动后关闭场景，再按F6启动，日期、资源、材料和人物应一致；在预览中退出重进不扣费。离场报告在重启后仍可查看。

下一步提案：接入集市第6—10天，承接渔村材料、传播、未决预警与处罚，开放三位人物及P1/P2调查。获得用户确认后再实施。
