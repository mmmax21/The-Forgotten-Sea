# 哑伯剧情配置与预览

剧情源于《文案配置表_渔村.xlsx》，整理在 `data/story/ya_bo.json`。查找船歌的地点已由仓库改为遗迹；未修改原始 Excel。剧情规则已接入行动结算、移动确认与独立存档。完整操作见 [运行说明](ruins_runtime.md)。

## 对话显示

旁白与人物台词共用底部文本框，点击文本框逐段推进。有说话人时显示“玩家：……”或“哑伯：……”，旁白不加姓名。哑伯的摇头、指向等动作保持旁白，不改写为口述。出示物品可用行动按钮、物品图标和旁白表现，无须额外绘制动作立绘。

F5 启动项目或 F6 运行 `scenes/ui/component_gallery.tscn`，点击哑伯后选择行动开始。五个原始事件及船骨、老渔夫后续已可连续游玩，文本框最后一句再次点击才结算。

## 已确认的剧情规则

1. 第一事件名为“哑伯的指引”，无需钥匙。
2. 完成指引后，抵达遗迹自动拾取古老的船歌。拾取不额外消耗行动点；完成后不重复发放。
3. 从哑伯住处前往遗迹、从遗迹返回哑伯住处，每次移动各消耗 1 AP。移动前显示确认弹窗，明确目的地及费用；取消不移动、不扣点，行动点不足时不能确认移动。确认并成功移动时仅扣一次。
4. 支持度明确为“哑伯支持度”。第一、第三事件不变；第四事件增加 10，重复播放不重复增加。
5. 演奏通过普通剧情对话表现，不做演奏小游戏。第四事件仍按原配置消耗交谈的 1 AP，不另收演奏费用。
6. 第五事件结果为“获得线索【造船图纸】；事件完成。”；第四事件旁白统一为“哑伯眼中第一次出现了清晰而强烈的情绪。”

往返移动与交谈分别计费：第一、第三、第四、第五事件各 1 AP，加上往返各 1 AP，完整流程共 6 AP（从哑伯住处开始计算，不含其他行动）。

JSON 提供文案、物品图片和规则说明；`scripts/story/ruins_state.gd` 执行当前固定章节的费用、顺序与奖励。它尚不是能自动执行任意 JSON 事件的通用剧情引擎。
